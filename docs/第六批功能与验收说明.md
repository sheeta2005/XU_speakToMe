## 复现方法

前端和完整隔离运维验收：

```powershell
node scripts/check-miniprogram.cjs
node --test tests/miniprogram/*.test.cjs
docker build -t speaktome:batch6-check .
pwsh -NoProfile -File scripts/smoke-ops.ps1 -Image speaktome:batch6-check
```

普通镜像构建未设置测试服务端口，会跳过 5 项真实 MySQL 和 4 项真实 Redis 测试，不能当作 88 项完整验收。CI 的后端任务独立提供 MySQL 8/Redis 7，并设置 `TEST_MYSQL_PORT`、`TEST_MYSQL_PASSWORD` 和 `TEST_REDIS_PORT` 后执行 clean verify。连接远端测试实例可另设 `TEST_MYSQL_HOST`、`TEST_REDIS_HOST`、`TEST_REDIS_PASSWORD`；只允许使用可销毁的测试数据库服务，迁移用例会创建并删除自己生成的随机测试库和参考库。

归档真实文件测试需要 Linux/macOS 的 POSIX 权限与目录同步语义；原生 Windows 会跳过这 4 项，请使用 Linux 容器完成全量验收。运维脚本要求 PowerShell 7.4+，原有演示脚本仍可使用 Windows PowerShell 5。

具体部署、接管、备份和灾备命令见[部署与运维](部署与运维.md)，本地启动见[快速开始](快速开始.md)。

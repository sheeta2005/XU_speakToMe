# 西邮点评家：功能清单与完成情况

检查日期：2026-10-16

检查范围：当前工作区源码、配置、数据库脚本、README 与一期方案。此文档记录代码检查结果，不代表已完成线上部署或真实服务联调。

## 项目目标

一期目标是面向西安邮电大学两个校区的校园美食点评小程序，主流程为：微信登录并选择校区，浏览地点、档口和菜品，查看评分与评论，发布或删除自己的点评，并由内容审核和管理员处理举报。二期交易、失物招领、跑腿和三期树洞、课程评价等目前只是方案与数据库预留，不属于一期待完成功能。

## 一期尚未完成的功能

1. **真实环境与前端验收**：举报、管理和个人中心已有自动化用例，但尚未使用微信开发者工具或真机核验布局、系统选择器、交互及主题，也未连接真实 MySQL、Redis 与微信服务验证完整登录、审核、举报和处理流程。
2. **配置与启动联调**：当前工作区的数据库名与 README/建库脚本不一致；配置文件中包含直接写入的数据库凭证和微信密钥，且 AES 密钥默认值为空。小程序配置的 AppID 与后端微信配置也不一致。需要确认同一小程序凭证、统一数据库名，并通过环境变量配置凭证及非空 AES 密钥，再验证真实调用。
3. **测试覆盖与内容校验**：本人点评、举报去重、管理权限、复审可见性和处理后的评分已有自动化测试；登录/加密、微信审核异常路径、限流切面、真实 Redis、多实例词库同步和并发缓存一致性仍需补充。现有资料接口的昵称敏感内容过滤也尚未接入。
4. **日志与上线运维**：落实审核日志归档后再清理、人工操作日志留存、数据库备份与恢复演练、线上 HTTPS/合法域名、日志脱敏、监控告警和发布验证。
5. **上线合规材料**：仓库未见隐私政策、用户协议、备案/类目审核、客服入口等交付材料；应按一期方案的合规清单核验后再提交审核。

- 第三批只提交举报和管理相关代码、必要回归修复、测试及文档；工作区原有本地配置及异常处理修改不纳入本批。

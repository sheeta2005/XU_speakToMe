# 西邮点评家：功能清单与完成情况

检查日期：2026-10-21

检查范围：当前工作区源码、配置、数据库脚本、README 与一期方案。此文档记录代码检查结果，不代表已完成线上部署或真实服务联调。

## 项目目标

一期目标是面向西安邮电大学两个校区的校园美食点评小程序，主流程为：微信登录并选择校区，浏览地点、档口和菜品，查看评分与评论，发布或删除自己的点评，并由内容审核和管理员处理举报。二期交易、失物招领、跑腿和三期树洞、课程评价等目前只是方案与数据库预留，不属于一期待完成功能。

## 一期尚未完成的功能

1. **真实微信与前端验收**：本机微信编译器已验证 12 个 WXML 和 14 个 WXSS；开发者工具页面运行及真机布局、选择器、交互、主题仍待核验，真实微信登录、审核与账号权限仍需联调。本地演示不调用微信，不代替真实审核验收。
2. **真实部署配置**：默认配置与数据库名已统一为环境变量，AES 在启动时校验；已有本地凭证单独保留并忽略。真实接入需配置自己的前后端微信凭证和 HTTPS 域名，并使用独立数据库与 Redis；如凭证曾公开暴露，应由持有者轮换。
3. **测试覆盖与内容校验**：本人点评、举报去重、管理权限、复审可见性、登录/加密、微信审核异常、限流切面及真实 Redis 已有自动化测试，CI 已提供。多实例词库同步、并发评分缓存一致性、昵称敏感内容过滤仍待完成；会话批量撤销仍为骨架。
4. **日志与上线运维**：落实审核日志归档后再清理、人工操作日志留存、数据库备份与恢复演练、线上 HTTPS/合法域名、日志脱敏、监控告警和发布验证。
5. **上线合规材料**：仓库未见隐私政策、用户协议、备案/类目审核、客服入口等交付材料；应按一期方案的合规清单核验后再提交审核。

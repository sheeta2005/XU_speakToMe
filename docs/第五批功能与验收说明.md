## 本机验证方式

准备 JDK 21、Node.js 22、Docker。只连接自己专用的测试 Redis；测试不执行 FLUSHDB，仅删除自己创建的键。

```powershell
docker run -d --name speaktome-test-redis -p 127.0.0.1:26379:6379 redis:7-alpine
$env:TEST_REDIS_PORT = '26379'
.\mvnw.cmd -B clean verify
node scripts/check-miniprogram.cjs
node --test tests/miniprogram/*.test.cjs
docker stop speaktome-test-redis
docker rm speaktome-test-redis
Remove-Item Env:TEST_REDIS_PORT
```

Linux/macOS 使用 `TEST_REDIS_PORT=26379 ./mvnw -B clean verify`。测试 Redis 可另设 `TEST_REDIS_HOST`、`TEST_REDIS_PASSWORD`；不设置端口会跳过 4 项真实 Redis 用例，其余测试照常运行，不能把这种运行记为完整验收。CI 明确配置端口并使用独立 Redis 服务。

微信编译器检查只适用于已经安装微信开发者工具的 Windows；参数传入含 `cli.bat` 的安装目录，不需要登录或上传：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-wechat.ps1 -DevToolsPath '你的微信开发者工具安装目录'
```

该脚本使用安装目录中的 wcc/wcsc 编译器，验证 WXML/WXSS 及样式导入。它不能启动页面、验证微信 API 宿主、判断视觉效果，也不代替当前基础库和真机兼容性检查。CI 不分发或安装这些专有编译器。

按[快速开始](快速开始.md)启动独立 demo 后，运行 `scripts/smoke-demo.ps1` 验证真实 MySQL、Redis、登录拦截、管理权限与点评流程，最后验证改变代理头不能绕过登录限流。脚本会触发本机登录限流，再次运行前应等待 60 秒，且不要用于生产环境。

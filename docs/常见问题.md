# 常见问题

## 能直接当正式服务上线吗？

本地 demo 可以按[快速开始](快速开始.md)体验，真实上线还需要自己的微信账号、域名、证书和服务器配置，并完成真实微信及真机验收。许可证尚待维护者确定，当前没有正式发布标签。剩余事项见[功能状态](项目功能清单与完成情况.md)和[发布检查](发布检查.md)。

## 为什么不用 npm install？

前端是原生微信小程序，目前没有 npm 依赖。导入 miniprogram 目录即可；页面逻辑测试单独需要 Node.js 22+。管理页也在小程序里，不存在另一个 Web 管理站点。

## `.env` 已存在，初始化脚本却报错？

脚本拒绝覆盖已有密钥，是预期行为。保留原文件，核对配置后继续启动。更换 AES_KEY 会使历史 openid 无法正常解密，更换配置里的数据库密码不会自动修改已有数据库账号。不要靠删卷或重新生成密钥解决启动问题。

## 浏览器能访问，手机却连不上？

127.0.0.1 在手机上指向手机本身。根目录 Compose 默认只绑定电脑回环地址；真机需单独配置能访问的测试服务与微信合法域名。开发者工具的“不校验合法域名”设置不代表正式环境可以使用 HTTP。

## 为什么演示评论总在复审中？

demo 不调用微信服务，故统一进入人工复审。用演示管理员在“我的 → 管理工作台 → 人工复审”通过后才公开。真实环境微信异常、微信建议复审或本地复审类词命中也会进入状态 3。不要为了看到评论而关闭审核。

## 普通浏览接口为什么返回未登录？

只有登录和校区列表公开；地点、档口、菜品、点评、榜单都要求 Bearer token。检查 JSON 中的 code，HTTP 200 不一定代表业务成功。Redis 会话默认 7 天，不会在每次读取时续期。

## 管理入口没有显示怎么办？

先查当前身份 auth/me，确认 role=1、status=1。首次真实管理员必须先登录创建用户，再按快速开始提升已核对 ID 的账号。重新进入个人中心刷新角色；重启 demo 不会覆盖已存在用户的角色。前端入口显示不替代后端权限检查。

## 停用地点后，子菜品怎么仍能查询？

当前是各级对象独立启停，没有统一的父级级联屏蔽规则，榜单也没有父级状态过滤。菜品 status 与 isAvailable 分别表示启停和在售。需要整层下线时应明确维护子对象；这是待完善的业务约束，不要假定改父级即可全部隐藏。

## 删除评论后，榜单怎么没马上变化？

评分会重算，评分分布缓存会失效；热门榜单每十分钟重建，存在延迟。榜单只统计窗口内 food/dish、审核通过且未删除的点评，目前跨校区。详情汇总均分与榜单热度所用窗口均分口径不同。

## Flyway 提示非空库没有历史记录？

已有无版本数据库必须先备份、停止写入，再按[部署与运维](部署与运维.md)核验接管。不要开启自动 baseline，不要改旧迁移校验和，也不要执行历史删表脚本。新业务字段应增加新的版本迁移。

## Windows 运行归档测试，为什么有跳过项？

持久化归档依赖 Linux/POSIX 的落盘语义，相应测试在原生 Windows 可能跳过；真实 MySQL/Redis 测试也依赖测试连接配置。完整验证以 Linux 容器或 CI 为准，不能只看到 BUILD SUCCESS 就认定所有测试都执行了。

## 备份和回滚包含什么？

运维脚本覆盖 MySQL、Redis 与审核归档，恢复到显式指定的空目标；AES 密钥仍需部署者单独安全保存。镜像回滚不等于数据库结构降级。异地副本、外部告警、正式服务器任务和证书续期仍需自己配置，详见部署文档。

## 有页面截图、真实微信和真机结果吗？

当前只有页面逻辑测试、本机 WXML/WXSS 编译及接口/容器验收记录；没有可交付的真实运行截图，也没有真实微信和真机验收结论。按[页面与截图清单](页面与截图清单.md)采集后再更新状态，不用设计稿代替运行截图。

## 交易、课程、头像上传能用吗？

不能。post、trade_order 是预留表，尚无对应服务和页面；头像接口只接收 URL，没有文件上传。昵称内容过滤、多实例词库同步、并发缓存一致性和批量会话撤销也仍待完善。

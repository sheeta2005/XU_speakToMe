# 页面与截图清单

截至 2026-10-24，以下 12 个页面已在 app.json 注册，**运行截图全部待采集**。已有逻辑测试和模板编译记录不等于运行截图或真机验收。本文件提供采集顺序，不伪造截图。

## 采集准备

1. 按[快速开始](快速开始.md)启动独立 demo，用演示同学与管理员准备数据。记录分支、完整提交号、开发者工具版本、基础库版本、设备/系统、采集日期和使用的后端环境。
2. 先采集日间主流程，再检查夜间、空列表、加载失败及重试。失败态可在隔离环境暂停后端后触发，恢复后验证重试。
3. 截图只保留测试内容，不包含真实用户身份、token、openid、AppSecret、证书或数据库凭证。不要采集开发者工具网络面板里的认证头。
4. 建议后续保存在 docs/images，文件名与下表对应；目前目录中没有这些文件，文档不引用不存在的图片。每张图片附环境及状态说明。

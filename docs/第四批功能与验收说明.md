# 第四批功能与验收说明

日期：2026-10-20。分支：`codex/quickstart-2026-10-20`，基于第三批 `ae7f083`。本批目标为本地克隆即可启动，按上一轮确认的开源模板第四批范围交付；真实微信、CI、生产运维和开源发布规范留在后续批次。

## 交付内容

- `.env.example` 与跨平台初始化脚本：随机生成 AES 密钥和数据库/Redis 密码，已有配置拒绝覆盖。
- 默认正式环境配置使用环境变量，校验 AES 长度与非 demo 凭证；本机默认回环地址；配置错误在创建业务组件前明确报出，不打印密钥。
- Maven Wrapper 固定 3.9.10，官方发行源与 SHA-256 校验；Docker 多阶段构建执行全模块测试，JRE 镜像使用非 root 用户。
- Compose 提供 MySQL 8、Redis 7 和应用；等待数据库建表及 Redis 健康后启动；使用普通数据库账号、命名卷和回环端口。
- `sql/init/01-schema.sql` 不含 DROP TABLE，空库建表与 `02-example-data.sql` 示例数据独立；旧重建脚本保留并明确不用于升级。
- 独立 demo Profile：两个固定身份，真实数据库/会话/权限/限流，微信内容审核替身统一转人工；禁止与 prod/local/其他 Profile 混用。
- 小程序接口配置按环境区分，仅开发版显示演示入口；体验及正式版禁止演示入口。
- 管理员脚本只对部署者确认的既有、未封禁用户 ID 提权；不设默认真实管理员，不增加公开提权 API。
- README 与快速开始覆盖演示、真实微信切换、管理员、宿主机开发、数据持久化和常见问题。

## 原有本地改动

既有后端 application.yml 原文保存在本机忽略目录 tmp/batch4-backup，并另存根目录忽略文件 application-local.yml。旧前端 app.js 和项目配置也已备份。跟踪配置整理为环境变量，小程序接口地址改由 config.js 管理。

既有 GlobalExceptionHandler.java 与个人项目配置不纳入本次提交。验证使用干净源码，以避免把本地凭证和未提交异常处理变化算作交付结果。
